# OBO Explorer

React + Vite template for  OBO graph visualisation.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run e2e tests with Cypress
npx cypress open

# Run component tests with Vitest
npm run test
```


MockData.ts is temporary fake data for testing purposes. It should be removed and replaced with FastAPI connection to the backend.
